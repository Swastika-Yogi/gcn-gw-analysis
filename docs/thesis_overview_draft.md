# Thesis Overview (Draft)

## Working title
**Rapid Chirp-Mass Estimation and AI-Assisted Analysis of Gravitational-Wave GCN Circulars**

## Overview

When gravitational-wave detectors flag a candidate compact-binary merger, full parameter estimation — the process that determines the source's mass, spin, and distance with confidence — can take hours to days. In that window, the only public information available is a stream of GCN Circulars: short, free-text bulletins written by the LVK collaboration and follow-up observers. Electromagnetic follow-up teams must decide where to point telescopes using only this text, before knowing, for instance, whether the merger even involved a neutron star. This thesis asks whether that text alone can support a fast, approximate estimate of chirp mass — the single parameter most informative about a merger's nature — and builds the tooling needed to test that question rigorously. The work has three parts.

**1. A reproducible circular-to-dataset pipeline, and a feasibility study of chirp-mass estimation.** A parsing pipeline converts the raw circular archive (45,000+ circulars) into a structured, per-event table with field-level provenance — distance, false alarm rate, source classification, and, where reported, reference chirp mass. Applied to the O4a observing run, this reveals that two of the three inputs a standard SNR-scaling chirp-mass formula requires (network SNR and orbital inclination) are structurally absent from circular text, not merely hard to parse. Testing the physics-based formula against 49 events where circulars self-report a reference chirp mass confirms this: it performs *worse* than a simple statistical model fit directly on distance (122% vs. 33% median error), because holding an assumed SNR fixed while distance varies over three orders of magnitude produces estimates that track distance, not mass. The statistical model gets the coarse mass bin right about half the time — a meaningful, if limited, result — and the thesis argues this reframing (predict the right bin, not a tight percentage) is itself the more honest target, since LVK's own low-latency pipeline reports mass this coarsely.

**2. A comparison study of general-purpose AI models on GW literature tasks.** Using a structured prompting framework, five free-tier LLMs (ChatGPT, Gemini, Claude, DeepSeek, Grok) are evaluated on their ability to classify, summarize, and cite parameters for real GW events without external tools. Early results show inconsistent reliability — models vary widely in whether they can correctly classify event types, provide sourced references, or report accurate numeric parameters from memory alone. This motivates the design constraint behind the third component below, and doubles as a literature-grounded discussion of LLM reliability in a specialized scientific domain, situating the thesis relative to recent work applying LLMs to GCN circulars and other noisy scientific text.

**3. GW Pathfinder: a design for a retrieval-grounded query tool.** Rather than relying on an LLM's unaided memory — shown in part 2 to be unreliable — GW Pathfinder is designed as a retrieval-grounded system: circular text is embedded and indexed, queries retrieve the relevant structured records (produced by the same pipeline as part 1), and an LLM response layer answers only from what was retrieved, citing source circulars. The chirp-mass estimator from part 1 plugs in as one inference module, invoked when an event lacks a directly reported mass, with its known error characteristics stated explicitly rather than presented as measurement. This component is documented as an architecture in this draft rather than fully implemented, given the project timeline.

## Contribution

The thesis's core contribution is not a proof that circular-level chirp-mass estimation works well — it doesn't, cleanly, and the thesis says so with evidence. The contribution is a reproducible, provenance-tracked pipeline; an honest, quantified feasibility result (including *why* the physics-motivated approach fails and what a data-driven alternative achieves instead); and a demonstrated, literature-grounded case for why any AI-assisted tool in this domain should be built on retrieval rather than model memory.
