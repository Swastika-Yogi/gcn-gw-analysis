\chapter{Conclusion and Recommendation}
\label{ch:conclusion}

\section{Summary of Findings}

This project set out to determine whether \gls{gcn} circular text alone can support a fast, approximate chirp-mass estimate. The answer, established with evidence rather than assumed: not reliably with the standard \gls{snr}-scaling physics formula, because network \gls{snr} and orbital inclination are structurally absent from circular text -- confirmed both by a data-availability audit and by the formula's failure even after properly calibrating its one free constant (Chapter~\ref{ch:results}). This was not left as an inference: cross-matching circular event IDs against the public \gls{gwtc} catalog and substituting real, measured \gls{snr} for the assumed value -- with nothing else about the formula changed -- cut the median error by roughly a third (Section~\ref{sec:catalog-validation}). This directly confirms that the physics formula itself is sound; it is specifically unusable \emph{from circulars alone}, because circulars cannot supply the input it depends on most. A promising, though only partial, way around this was also tested: false alarm rate, which circulars \emph{do} report, predicts real SNR with 10.7\% median error when properly fit against the catalog -- but applying that proxy to the circular-only set gives only a modest gain, traceable to those events sitting in a harder-to-predict FAR range rather than to any flaw in the proxy itself. A statistical alternative based on distance alone performs better than the circular-only physics formula; on the small circular-only sample a trivial classification-based baseline looked competitive with it, but that was an artifact of near-zero class diversity in that sample, not a genuine distance-class relationship -- resolved directly using the catalog-backed set's real diversity, where distance alone outperforms class alone and combining the two adds nothing. At that larger scale, the distance-only statistical model is competitive with the physics formula even when the latter is given real SNR, a notable result in its own right: the simplest circular-derivable model matches a physically-motivated one that needs information circulars cannot supply. A further, secondary lever on the physics formula was tested directly: its calibration constant genuinely differs by observing-run era (O3 vs.\ O4, plausibly real detector-network changes), and era-specific calibration cuts its real-SNR error further, from 31.5\% to 26.6\% -- a real but smaller gain than SNR itself, and one where finer per-run splits actively overfit on the smaller runs rather than helping (Section~\ref{sec:catalog-validation}).

\section{Contribution}

The core contribution is not a proof that circular-level chirp-mass estimation works well -- it does not, cleanly, and this report states that plainly. The contribution is: a reproducible, provenance-tracked pipeline converting unstructured circular text into a structured, auditable dataset; an honest, quantified feasibility result that explains \emph{why} the physics-motivated approach falls short and what a data-driven alternative achieves instead; and a literature-grounded case, backed by a direct comparison study, for why an AI-assisted tool in this domain should be built on retrieval rather than model memory.

\section{Limitations}

\begin{itemize}
    \item The circular-only validation set is small (49 events); leave-one-out cross-validation reduces, but does not eliminate, overfitting risk at this sample size. The catalog-backed set (214 events) is substantially larger but excludes 153 confirmed events with no public circular -- low-significance, offline-catalog-only detections, not a pipeline defect (Section~\ref{sec:catalog-validation}).
    \item Circular-self-reported reference-mass events are, by construction, drawn from later observing runs than O4a, since O4a circulars never report this field; O4a data contributed to the availability audit and to the catalog-backed validation set, but not to the circular-only one.
    \item The statistical model uses distance alone; \gls{far} and classification probability were tested as additional predictors and did not help at this sample size, though this may change as the archive accumulates more circulars with reference chirp mass.
    \item Even with real \gls{snr} from the catalog, the physics formula still assumes a fixed orientation (never marginalized or measured) -- the likely remaining reason error stays at 26.6\%, not near-zero, even once \gls{snr} is real and calibration is era-specific rather than global (Section~\ref{sec:catalog-validation}: per-era calibration was the only stratification stable enough to help; finer per-run splits overfit on the smaller runs).
\end{itemize}

\section{Recommendation}

Given the coarse, bin-quantized nature of the reference chirp mass values circulars do report, this project recommends that future work on this problem adopt ``predict the correct mass bin'' rather than a fixed percentage-error target as the primary success criterion, since the latter implicitly demands more precision than the ground truth itself provides.

\section{Future Work}

\begin{itemize}
    \item Test orientation marginalization against the 214-event catalog-backed set, now that real \gls{snr} removes it as the dominant confound -- the next most promising lever on the remaining 26.6\% median error (era-specific calibration, the other lever originally planned here, is now done: Section~\ref{sec:catalog-validation}). Network-specific (as opposed to run-specific) calibration remains untested.
    \item Re-verify the \gls{far}-to-\gls{snr} proxy's accuracy once the circular-only validation events themselves enter a future GWTC release (Section~\ref{sec:catalog-validation}) -- currently the proxy's downstream performance on that exact population can only be inferred from its accuracy in the FAR range those events fall into, not checked directly.
    \item Test finer-grained class information (per-class dummies, or continuous classification probability rather than a binary BBH split) once \gls{nsbh}/\gls{bns} sample sizes grow -- the current catalog-backed set (5 \gls{nsbh}, 1 \gls{bns}) settled whether class helps at all beyond distance (Section~\ref{sec:catalog-validation}: it does not, at this granularity) but is too thin to test finer distinctions.
    \item Develop an uncertainty-aware estimator rather than a point estimate.
    \item Complete the AI-model comparison study on a larger, fresh event batch, and complete a working (not just designed) GW Pathfinder prototype.
    \item Extract sky-localization area (present in 59.2\% of events, Section~\ref{sec:direct-vs-approximated}) and test it as a candidate weak proxy for detector-network geometry, alongside other circular-derivable parameters beyond chirp mass (detector count, event time) not yet incorporated into the pipeline.
    \item Prepare a publication-quality version of the statistical analysis for the strongest result, per the project's longer-term research-paper goal.
\end{itemize}
